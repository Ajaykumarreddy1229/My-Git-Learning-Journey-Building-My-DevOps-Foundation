📚 Topics I Have Learned
1. Version Control System

I learned why Version Control Systems are important for:

Tracking code changes
Maintaining different versions of code
Collaborating with developers
Recovering previous versions
Managing projects safely
2. Git

Git is a Distributed Version Control System used to track changes in source code and collaborate with other developers.

3. Git Architecture

The basic Git workflow consists of:

      ↓
Staging Area
      ↓

      ↓

      ↓
GitHub

6. Git Fork

A Fork creates a copy of another user's GitHub repository under my own GitHub account.

The basic workflow I learned is:

Original Repository
        ↓
      Fork
        ↓
My GitHub Repository
        ↓
      Clone
        ↓
Local Repository
        ↓
      Changes
        ↓
      Commit
        ↓
       Push
        ↓
   Pull Request

This allows developers to work on someone else's project without directly modifying the original repository.
